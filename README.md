# FourCardFeatureSection
This is my solution to the **Four Card Feature Section** challenge from Frontend Mentor.  
The project focuses on building a clean and responsive layout that matches the provided design as closely as possible using only HTML and CSS.

## Overview
The page presents a modern feature section that highlights four different tools or services.  
The layout is mobile-first and becomes a multi-column design on larger screens.

## Built With
- Semantic **HTML5**
- **CSS3** (Flexbox & Responsive Design)
- Google Fonts (Poppins)

## Features
- Responsive layout for mobile and desktop screens  
- Clean and structured HTML  
- Flexbox used for layout alignment  
- Card design with shadows and colored top borders  
- Accurate spacing and typography based on the design

## Responsive Behavior
- On small screens, cards are stacked vertically  
- On larger screens (1000px+), cards are arranged in columns with the middle cards grouped together
